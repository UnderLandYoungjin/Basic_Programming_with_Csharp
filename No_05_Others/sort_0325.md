## 1. 배열 선언과 초기화

### 📌 배열이란?

배열(Array)은 **같은 타입**의 데이터를 연속된 메모리 공간에 저장하는 자료구조입니다.

- 한 번 생성하면 **크기 변경 불가** (고정 길이)
- 인덱스는 **0부터** 시작
- `Length` 속성으로 배열 크기 확인 가능

### 📌 선언 방법 4가지

```csharp
// 방법 1: 크기만 지정 (기본값으로 초기화)
int[] numbers = new int[5];
// → {0, 0, 0, 0, 0}

// 방법 2: new 키워드 + 초기값
int[] scores = new int[] { 85, 92, 78, 95, 88 };

// 방법 3: 축약형 (가장 간결)
int[] ages = { 20, 22, 19, 25, 21 };

// 방법 4: string 배열
string[] names = { "김철수", "이영희", "박민수" };
```

### 💻 실습 1-1: 배열 선언 후 출력하기

```csharp
using System;

class Program
{
    static void Main()
    {
        // 크기만 지정한 배열 (기본값 0)
        int[] numbers = new int[5];
        Console.WriteLine("=== 기본값 배열 ===");
        Console.WriteLine($"배열 크기: {numbers.Length}");
        for (int i = 0; i < numbers.Length; i++)
        {
            Console.Write($"{numbers[i]} ");
        }
        Console.WriteLine();

        // 초기값이 있는 배열
        int[] scores = { 85, 92, 78, 95, 88 };
        Console.WriteLine("\n=== 초기값 배열 ===");
        Console.WriteLine($"배열 크기: {scores.Length}");
        for (int i = 0; i < scores.Length; i++)
        {
            Console.Write($"scores[{i}] = {scores[i]}  ");
        }
        Console.WriteLine();

        // string 배열
        string[] names = { "김철수", "이영희", "박민수" };
        Console.WriteLine("\n=== 문자열 배열 ===");
        foreach (string name in names)
        {
            Console.Write($"\"{name}\" ");
        }
        Console.WriteLine();
    }
}
```

**실행 결과:**
```
=== 기본값 배열 ===
배열 크기: 5
0 0 0 0 0

=== 초기값 배열 ===
배열 크기: 5
scores[0] = 85  scores[1] = 92  scores[2] = 78  scores[3] = 95  scores[4] = 88

=== 문자열 배열 ===
"김철수" "이영희" "박민수"
```

```csharp
            if (i < arr.Length - 1) Console.Write(", ");
        }
        Console.WriteLine(" }");
    }
}
```

## 2. 배열 요소 접근과 수정

### 📌 인덱스(Index) 규칙

```
배열:  [ 10 ] [ 20 ] [ 30 ] [ 40 ] [ 50 ]
인덱스:  [0]    [1]    [2]    [3]    [4]
```

- 첫 번째 요소: `arr[0]`
- 마지막 요소: `arr[arr.Length - 1]`
- 범위 초과 시: **`IndexOutOfRangeException`** 발생!

### 📌 읽기와 쓰기

```csharp
int[] arr = { 10, 20, 30, 40, 50 };

// 읽기
int first = arr[0];        // 10
int last = arr[4];         // 50
int len = arr.Length;      // 5

// 쓰기
arr[2] = 99;               // { 10, 20, 99, 40, 50 }

// ⚠️ 주의! 범위 초과 → 예외 발생
// arr[5] = 60;  → IndexOutOfRangeException!
```

### 💻 실습 2-1: 인덱스 접근 체험

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] arr = { 10, 20, 30, 40, 50 };

        Console.WriteLine("=== 배열 요소 접근 ===");
        Console.WriteLine($"배열: [ {string.Join(", ", arr)} ]");
        Console.WriteLine($"배열 크기(Length): {arr.Length}");
        Console.WriteLine();

        // 각 인덱스 출력
        for (int i = 0; i < arr.Length; i++)
        {
            Console.WriteLine($"  arr[{i}] = {arr[i]}");
        }

        Console.WriteLine();

        // 값 수정
        Console.WriteLine("--- arr[2] = 99 실행 ---");
        int oldValue = arr[2];
        arr[2] = 99;
        Console.WriteLine($"arr[2]: {oldValue} → {arr[2]}");
        Console.WriteLine($"배열: [ {string.Join(", ", arr)} ]");
    }
}
```

### 💻 실습 2-3: 대화형으로 읽기/쓰기

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] arr = { 10, 20, 30, 40, 50 };

        while (true)
        {
            Console.WriteLine($"\n현재 배열: [ {string.Join(", ", arr)} ]");
            Console.WriteLine("1) 읽기  2) 쓰기  3) 종료");
            Console.Write("선택: ");
            string choice = Console.ReadLine();

            if (choice == "3") break;

            Console.Write("인덱스: ");
            int idx = int.Parse(Console.ReadLine());

            try
            {
                if (choice == "1")
                {
                    Console.WriteLine($"✅ arr[{idx}] = {arr[idx]}");
                }
                else if (choice == "2")
                {
                    Console.Write("새 값: ");
                    int val = int.Parse(Console.ReadLine());
                    int old = arr[idx];
                    arr[idx] = val;
                    Console.WriteLine($"✅ arr[{idx}]: {old} → {val}");
                }
            }
            catch (IndexOutOfRangeException)
            {
                Console.WriteLine($"❌ IndexOutOfRangeException! (유효 범위: 0~{arr.Length - 1})");
            }
            catch (FormatException)
            {
                Console.WriteLine("❌ FormatException! 숫자만 입력 가능합니다.");
            }
        }
    }
}
```

## 3. 반복문으로 배열 순회

### 📌 for 문 vs foreach 문

```csharp
int[] arr = { 15, 27, 33, 41, 58, 62, 79 };

// for 문: 인덱스가 필요할 때
for (int i = 0; i < arr.Length; i++)
{
    Console.WriteLine($"arr[{i}] = {arr[i]}");
}

// foreach 문: 값만 필요할 때 (더 간결)
foreach (int num in arr)
{
    Console.WriteLine(num);
}
```

### 📌 for vs foreach 비교

| 구분 | for | foreach |
|------|-----|---------|
| 인덱스 접근 | ✅ 가능 | ❌ 불가 |
| 요소 수정 | ✅ 가능 (`arr[i] = 값`) | ❌ 불가 (읽기 전용) |
| 코드 간결성 | 보통 | ✅ 간결 |
| 역순 순회 | ✅ 가능 | ❌ 불가 |

### 💻 실습 3-1: for 문 순회

```csharp
using System;
```

## 4. 배열 정렬

### 📌 내장 메서드로 정렬

```csharp
int[] arr = { 64, 34, 25, 12, 22, 11, 90, 45 };

// 오름차순 정렬
Array.Sort(arr);
// → { 11, 12, 22, 25, 34, 45, 64, 90 }

// 내림차순 (오름차순 후 뒤집기)
Array.Reverse(arr);
// → { 90, 64, 45, 34, 25, 22, 12, 11 }
```

### 📌 버블 정렬 직접 구현

```csharp
// 인접한 두 요소를 비교하여 교환하는 정렬
for (int i = 0; i < arr.Length - 1; i++)
{
    for (int j = 0; j < arr.Length - 1 - i; j++)
    {
        if (arr[j] > arr[j + 1])
        {
            int temp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = temp;
        }
    }
}
```

### 💻 실습 4-2: 버블 정렬 과정 시각화

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] arr = { 64, 34, 25, 12, 22, 11, 90, 45 };

        Console.WriteLine("=== 버블 정렬 시작 ===");
        Console.Write("원본: [ ");
        Console.Write(string.Join(", ", arr));
        Console.WriteLine(" ]");
        Console.WriteLine();

        int swapCount = 0;

        for (int i = 0; i < arr.Length - 1; i++)
        {
            Console.WriteLine($"--- 패스 {i + 1} ---");

            for (int j = 0; j < arr.Length - 1 - i; j++)
            {
                if (arr[j] > arr[j + 1])
                {
                    // 교환
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                    swapCount++;

                    Console.Write($"  🔄 arr[{j}]↔arr[{j + 1}] → [ ");
                    Console.Write(string.Join(", ", arr));
                    Console.WriteLine(" ]");
                }
            }
        }

        Console.WriteLine($"\n✅ 정렬 완료! (교환 {swapCount}회)");
        Console.Write("결과: [ ");
        Console.Write(string.Join(", ", arr));
        Console.WriteLine(" ]");
    }
}
```

## 5. 배열 검색

### 📌 검색 방법 정리

```csharp
int[] arr = { 23, 45, 12, 67, 34, 89, 56, 78, 11, 90 };

// Array.IndexOf — 값의 인덱스 반환 (없으면 -1)
int idx = Array.IndexOf(arr, 67);    // 3

// Array.Contains (using System.Linq 필요)
bool found = arr.Contains(67);       // true

// 최대값, 최소값 (using System.Linq 필요)
int max = arr.Max();  // 90
int min = arr.Min();  // 11
```

### 📌 선형 검색 직접 구현

```csharp
int target = 67;
int foundIndex = -1;

for (int i = 0; i < arr.Length; i++)
{
    if (arr[i] == target)
    {
        foundIndex = i;
        break;
    }
}

if (foundIndex >= 0)
    Console.WriteLine($"찾았습니다! 인덱스: {foundIndex}");
else
    Console.WriteLine("찾지 못했습니다.");
```

### 💻 실습 5-1: 선형 검색 과정 시각화

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] arr = { 23, 45, 12, 67, 34, 89, 56, 78, 11, 90 };

        Console.Write("배열: [ ");
        Console.Write(string.Join(", ", arr));
        Console.WriteLine(" ]");
        Console.Write("\n검색할 값: ");
        int target = int.Parse(Console.ReadLine());

        Console.WriteLine($"\n📌 선형 검색 시작: target = {target}");
        Console.WriteLine("---");

        bool found = false;
        for (int i = 0; i < arr.Length; i++)
        {
            if (arr[i] == target)
            {
                Console.WriteLine($"  arr[{i}] = {arr[i]} == {target} → ✅ 찾았습니다!");
                found = true;
                break;
            }
            else
            {
                Console.WriteLine($"  arr[{i}] = {arr[i]} ≠ {target}");
            }
        }

        if (!found)
        {
            Console.WriteLine($"  ❌ {target}을(를) 찾지 못했습니다.");
        }
    }
}
```

**실행 결과 (target = 67):**
```
배열: [ 23, 45, 12, 67, 34, 89, 56, 78, 11, 90 ]

검색할 값: 67

📌 선형 검색 시작: target = 67
---
  arr[0] = 23 ≠ 67
  arr[1] = 45 ≠ 67
  arr[2] = 12 ≠ 67
  arr[3] = 67 == 67 → ✅ 찾았습니다!
```

### 💻 실습 5-3: 특정 조건으로 검색

### 📝 문제 1: 성적 처리 프로그램

5명의 학생 성적을 배열에 입력받아 평균, 최고점, 최저점, 정렬 결과를 출력하세요.

```csharp
using System;
using System.Linq;

class Program
{
    static void Main()
    {
        int[] scores = new int[5];

        // 입력
        Console.WriteLine("=== 성적 처리 프로그램 ===");
        for (int i = 0; i < scores.Length; i++)
        {
            Console.Write($"학생 {i + 1} 점수: ");
            scores[i] = int.Parse(Console.ReadLine());
        }

        // 처리
        int sum = 0;
        foreach (int s in scores) sum += s;
        double avg = (double)sum / scores.Length;

        Console.WriteLine("\n=== 결과 ===");
        Console.WriteLine($"전체 점수: [ {string.Join(", ", scores)} ]");
        Console.WriteLine($"합계: {sum}");
        Console.WriteLine($"평균: {avg:F1}");
        Console.WriteLine($"최고점: {scores.Max()}");
        Console.WriteLine($"최저점: {scores.Min()}");

        int[] sorted = (int[])scores.Clone();

            else if (scores[i] >= 80) grade = "B";

            else if (scores[i] >= 60) grade = "D";
            else grade = "F";

            Console.WriteLine($"학생 {i + 1}: {scores[i]}점 → {grade}");
        }
    }
}
```

### 📝 문제 2: 배열 뒤집기 (Array.Reverse 사용 금지!)

```csharp
using System;

class Program
{
    static void Main()
    {
        int[] arr = { 1, 2, 3, 4, 5 };

        Console.Write("원본: [ ");
        Console.Write(string.Join(", ", arr));
        Console.WriteLine(" ]");
        Console.WriteLine();

        // 직접 뒤집기
        Console.WriteLine("=== 뒤집기 과정 ===");
        for (int i = 0; i < arr.Length / 2; i++)
        {
            int oppositeIdx = arr.Length - 1 - i;
            Console.WriteLine($"  arr[{i}]({arr[i]}) ↔ arr[{oppositeIdx}]({arr[oppositeIdx]})");

            int temp = arr[i];
            arr[i] = arr[oppositeIdx];
            arr[oppositeIdx] = temp;

            Console.Write("  → [ ");
            Console.Write(string.Join(", ", arr));
            Console.WriteLine(" ]");
        }

        Console.Write("\n결과: [ ");
        Console.Write(string.Join(", ", arr));
        Console.WriteLine(" ]");
    }
}
```

```
=== 뒤집기 과정 ===
  arr[0](1) ↔ arr[4](5)
  → [ 5, 2, 3, 4, 1 ]
  arr[1](2) ↔ arr[3](4)
  → [ 5, 4, 3, 2, 1 ]
```

### 📝 문제 3: 로또 번호 생성기 (도전!)

1~45 중 중복 없이 6개의 랜덤 번호를 뽑아 정렬하여 출력하세요.

```csharp
using System;

class Program
{

    {

                    break;
                }

            }
        }

        // 정렬
        Array.Sort(lotto);

        // 출력
        Console.Write("당첨 번호: ");
        for (int i = 0; i < lotto.Length; i++)
```

### 📝 문제 4: 배열로 간단한 메뉴 프로그램

```csharp
using System;
using System.Linq;

class Program
{
    static void Main()
    {
        int[] data = new int[0]; // 빈 배열에서 시작

        while (true)
        {
            Console.WriteLine("\n=============================");
            Console.WriteLine("  📦 배열 관리 프로그램");
            Console.WriteLine("=============================");
            Console.WriteLine($"  현재 배열: [ {string.Join(", ", data)} ]");
            Console.WriteLine($"  크기: {data.Length}");
            Console.WriteLine("-----------------------------");
            Console.WriteLine("  1. 배열 새로 만들기");
            Console.WriteLine("  2. 값 추가 (배열 확장)");
            Console.WriteLine("  3. 전체 출력");
            Console.WriteLine("  4. 합계/평균");
            Console.WriteLine("  5. 정렬 (오름차순)");
            Console.WriteLine("  6. 검색");
            Console.WriteLine("  7. 뒤집기");
            Console.WriteLine("  0. 종료");
            Console.WriteLine("-----------------------------");
            Console.Write("  선택: ");

            string choice = Console.ReadLine();

            switch (choice)
            {
                case "1":
                    Console.Write("배열 크기: ");
                    int size = int.Parse(Console.ReadLine());
                    data = new int[size];
                    for (int i = 0; i < size; i++)
                    {
                        Console.Write($"  [{i}] 값: ");
                        data[i] = int.Parse(Console.ReadLine());
                    }
                    Console.WriteLine("✅ 배열 생성 완료!");
                    break;

                case "2":
                    Console.Write("추가할 값: ");
                    int newVal = int.Parse(Console.ReadLine());
                    int[] newArr = new int[data.Length + 1];
                    Array.Copy(data, newArr, data.Length);
                    newArr[data.Length] = newVal;
                    data = newArr;
                    Console.WriteLine($"✅ {newVal} 추가됨 (크기: {data.Length})");
                    break;

                case "3":
                    if (data.Length == 0) { Console.WriteLine("❌ 배열이 비어있습니다."); break; }
                    for (int i = 0; i < data.Length; i++)
                        Console.WriteLine($"  data[{i}] = {data[i]}");
                    break;

                case "4":
                    if (data.Length == 0) { Console.WriteLine("❌ 배열이 비어있습니다."); break; }
                    int sum = 0;
                    foreach (int n in data) sum += n;
                    Console.WriteLine($"  합계: {sum}");
                    Console.WriteLine($"  평균: {(double)sum / data.Length:F1}");
                    Console.WriteLine($"  최대: {data.Max()}");
                    Console.WriteLine($"  최소: {data.Min()}");
                    break;

                case "5":
                    Array.Sort(data);
                    Console.WriteLine($"✅ 정렬 완료: [ {string.Join(", ", data)} ]");
                    break;

                case "6":
                    Console.Write("검색할 값: ");
                    int target = int.Parse(Console.ReadLine());
                    int idx = Array.IndexOf(data, target);
                    if (idx >= 0)
                        Console.WriteLine($"✅ 인덱스 {idx}에서 발견!");
                    else
                        Console.WriteLine("❌ 찾지 못했습니다.");
                    break;

                case "7":
                    Array.Reverse(data);
                    Console.WriteLine($"✅ 뒤집기 완료: [ {string.Join(", ", data)} ]");
                    break;

                case "0":
                    Console.WriteLine("프로그램을 종료합니다.");
                    return;
            }
        }
    }
}
```

## ⚠️ 자주 하는 실수

### 1. IndexOutOfRangeException
```csharp
int[] arr = new int[5];
arr[5] = 10; // ❌ 인덱스는 0~4까지!
```

### 2. for문 조건 실수
```csharp
// ❌ 잘못된 코드 (i <= arr.Length → 마지막에 에러)
for (int i = 0; i <= arr.Length; i++) { }

// ✅ 올바른 코드
for (int i = 0; i < arr.Length; i++) { }
```

### 3. foreach에서 값 수정 시도
```csharp
// ❌ foreach 변수는 읽기 전용!
foreach (int n in arr)
{
    n = n * 2; // 컴파일 에러!
}

// ✅ for 문을 사용해야 함
for (int i = 0; i < arr.Length; i++)
{
    arr[i] = arr[i] * 2;
}
```

### 4. 배열 크기는 변경 불가
```csharp
int[] arr = new int[3];
// arr의 크기를 5로 바꾸고 싶다면?
// → Array.Resize 또는 새 배열 만들어 복사
Array.Resize(ref arr, 5);
```
