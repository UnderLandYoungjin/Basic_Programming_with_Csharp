인트로소트 (IntroSort) — C# Array.Sort()의 실체

IntroSort는 3가지 정렬을 상황에 맞게 전환하는 하이브리드 알고리즘입니다. QuickSort의 빠른 평균 성능 + HeapSort의 최악 O(n log n) 보장 + InsertionSort의 소규모 효율성을 결합합니다.

① QuickSort 시작
→
② 재귀 깊이 초과 → HeapSort
→
③ 파티션 ≤16 → InsertionSort

버블 정렬

인접 요소를 반복 비교·교환. O(n²). 가장 단순하지만 가장 느림.

선택 정렬

매번 최솟값을 찾아 앞에 배치. O(n²). 교환 횟수가 적음.

삽입 정렬

올바른 위치에 삽입. O(n²)이지만 거의 정렬된 데이터에서 O(n). IntroSort의 마무리 단계.

힙 정렬

최대 힙을 구성한 뒤 루트를 반복 추출. 항상 O(n log n) 보장. IntroSort가 최악 상황에서 전환하는 안전망.

퀵 정렬

피벗 기준 분할정복. 평균 O(n log n), 최악 O(n²). IntroSort의 주력 엔진.
